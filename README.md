# VacRecap

Reisetagebuch als offline-fähige PWA (Vanilla HTML/CSS/JS, IndexedDB). Paketweise Aufbau für Dominiks Urlaub.

## Lokal testen

```bash
python3 -m http.server 8080
# http://localhost:8080/
```

## GitHub Pages

Öffentliches Repo, Branch `main`, Quelle „GitHub Actions“. Die App liegt unter `/VacRecap/` (Projekt-Page).

Siehe Pull Requests für den aktuellen Paket-Stand und Testliste.
